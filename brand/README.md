# Brand

The site is a public register: plain paper, near-black type, and one ink,
the violet-blue of an official rubber stamp. The mark is the nine-eyed sun
(ცხრათვალა მზე).

## Colours

| Name | Light | Dark | Use |
|---|---|---|---|
| Paper | `#F4F4F1` | `#15161A` | Background |
| Ink | `#1B1D21` | `#E9E9EC` | Text |
| Graphite | `#5B6068` | `#A0A3AB` | Secondary text |
| Rule | `#D3D4D6` | `#30323A` | Lines |
| Stamp | `#3B3A9F` | `#ABA8F2` | The mark, stamps, actions |
| Stamp wash | `#E7E6F5` | `#25244A` | Tinted panels |
| On stamp | `#FBFBF9` | `#15161A` | Text and mark on a stamp-coloured fill |

## Type

Archivo (variable, the `wdth` axis wide for headlines) and Noto Sans
Georgian. Both are free (SIL Open Font License).
